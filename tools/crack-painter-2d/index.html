01 / The idea

A crate should
break like a crate.

A wooden crate has planks. A wall has mortar. Those details tell us how an object should come apart.

I built Crack Painter 2D to put that decision in the designer’s hands. Draw the break along the artwork’s seams, then turn those choices into pieces Unity can simulate.

The design principle

Choose the fracture.
Keep the feeling tunable.

02 / The workflow

Paint. Check. Bake.
Break.

The authoring happens inside Unity. The output is a normal prefab. Everything between those two points should make a designer’s job easier.

  1. 01/

    Paint the intent.

    Draw magenta cracks over the sprite. Brush, erase, draw straight lines, zoom in, undo. The crack map is an ordinary PNG, so an external art editor works too.

    Your sprite + your crack map
  2. 02/

    See what separates.

    Auto Check runs the split validation after each stroke. Freed pieces turn grey; lines that don’t separate anything turn red. Find the missing pixel before it becomes a wasted bake.

    Live feedback, before committing
  3. 03/

    Make it playable.

    One bake creates the fragment sprites, colliders, rigidbodies and shatter component. Drop the prefab into a scene, choose a trigger and tune how the break feels.

    One prefab, ready for Physics 2D

03 / The design decisions

A tool is only good
if it’s good
to use.

My work was as much about the authoring experience as the shatter effect. These are the decisions that shaped it.

Paul Schwab ↗
Tool design & development
01 / Feedback

Make the invisible mistake visible.

A crack can look finished while stopping one pixel short of a boundary. I used the baker’s flood fill in the painting view, so the editor shows what will actually separate. The feedback answers the question where it comes up.

02 / Ownership

Keep the output ordinary.

The map is a PNG. The result is a Unity prefab with standard components. That makes the work inspectable and editable, and lets it fit a project’s existing layers, sorting and materials.

03 / Iteration

Separate the shape from the feeling.

The crack pattern is authored once. Force, lift, spin and gravity stay adjustable at runtime. A designer can change a gentle collapse into a punchy burst without repainting or baking the sprite again.

04 / Scope

Be clear about the tradeoff.

Hand-authored cracks take time, but give important props a specific way to break. This tool uses patterns baked in advance; arbitrary runtime cutting and carving are outside its scope.

04 / In Unity

Same pieces.
Different impact.

The pattern defines the shape. The component defines the response.
